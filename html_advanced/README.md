# HTML, advanced

Building the "SmileSchool" landing page from scratch, using pure HTML
semantic markup based on a Figma wireframe design. No CSS or styling yet —
this project focuses entirely on correct, meaningful HTML structure:
header, banner, quote, videos list, membership section, FAQ, and footer.

![Wireframe](./images/wireframe.png)

## Structure

The page follows this layout, from top to bottom:
1. **Header** — logo + navigation links
2. **Banner** — hero heading, CTA button, and a row of instructor cards
3. **Quote** — a testimonial block with image and quote
4. **Videos list** — grid of tutorial video cards with ratings
5. **Membership** — call-to-action section for free membership
6. **FAQ** — two rows of question/answer pairs
7. **Footer** — logo, social links, and closing text
